# Java Typing Speed Trainer

A command-line Java application that measures typing speed and accuracy by asking the user to type randomly selected paragraphs. The program calculates Words Per Minute (WPM), typing accuracy, and tracks the user's highest typing speed.

This project demonstrates core programming concepts such as file handling, timing functions, string comparison and user interaction in Java.

---

## Features

• Multiple difficulty levels (Easy, Medium, Hard)  
• Random paragraph generation for each test  
• Countdown timer before typing begins  
• Words Per Minute (WPM) calculation using the standard 5-character rule  
• Typing accuracy calculation  
• Error detection for mismatched characters  
• Persistent high score tracking using file storage  
• Session statistics (tests completed and average speed)  
• Clean and interactive command-line interface
